# 模拟与混合信号电路研究

把电路研究整理为可用于理解和设计的技术笔记。研究深度服从用户的问题：局部公式分析不必扩展为完整综述；新拓扑研究应覆盖机理、关键性能与设计边界。

## 确定研究范围

- 优先读取用户给出的原理图、论文、仿真结果及现有笔记，辨认具体拓扑和版本。
- 若只给出名称，选择一个明确的基础结构作为分析对象，说明选择和限制。缺少晶体管级连接时，可以研究功能级模型，但不要将其称为可直接实现的完整电路。
- 定义输入、输出、节点、器件、极性、负载和指标；时变电路还要定义各阶段、初始条件、时钟顺序和信号路径。
- 区分研究说明、解析设计示例和针对指定工艺的设计。没有 PDK、规格或实际原理图，不声称已完成器件尺寸设计或可靠性验证。
- 在 Circuits & Systems Classroom 中工作时，按需读取 [项目约定](references/classroom-conventions.md)。其他项目以当地约定为准。

## 建立证据与模型

- 优先使用原始论文、教材和工艺文档。重要外部结论就近注明来源；能读取全文时记录章节、页码、图号或公式号。只有摘要或书目记录时明确标注访问范围。
- 原理图来自不同文献时分别定义版本，不能拼接公式而省略结构差异。现有笔记是待核对材料，不是正确性的证明。
- 无法获取某来源时，继续可独立完成的推导，并记录未核实项。不要编造文献、图号、性能数字或仿真结果。
- 建立符号与假设表：器件工作区、是否计入体效应和输出电阻、寄生及负载、单端/差分定义、时域/频域以及模型的有效范围。
- 整理系列文章或处理 PDF 时，按需读取 [资料入库与全文核对](references/source-ingestion.md)。转换 Markdown 只辅助研究；专题可结合其他原始来源和独立推导扩展。

## 从机理推导结果

- 先解释电流路径、电荷转移、能量或反馈关系，再从 KCL、KVL、电荷守恒或状态方程得到结论；保留足以复核的中间步骤。
- 区分模型内的等式、工程近似和经验规则。给出近似成立条件，不把某论文的测量或特定工艺经验当作通用设计规则。
- 时变电路区分瞬时小信号参数、整个周期的增益、积分响应和最终采样值，避免直接套用静态放大器公式。
- 噪声分析注明 PSD 的单双边约定、输入/输出参考点、积分带宽、相关性和采样条件。区分 V²/Hz、V/√Hz 与积分后的 V²；说明折叠或相关采样是否进入模型。
- 稳定性分析定义反馈路径、环路增益和符号；区分 rad/s 与 Hz。建立时间区分小信号指数响应、压摆和动态偏置。

## 选择相关的非理想因素

根据结构和研究目标选取内容，不要求每篇笔记包含所有指标：

| 电路类型 | 优先分析 |
|---|---|
| 放大器与反馈电路 | 增益、共模、噪声、稳定性、建立、压摆、功耗 |
| 采样与开关电路 | 阶段与电荷守恒、导通电阻、失真、热噪声、注入、馈通、寄生、端间应力 |
| 比较器与再生电路 | 再生时间、失调、判决噪声、回踢、输入共模、亚稳态 |
| 动态或电荷域电路 | 初始状态、周期响应、能量/电荷预算、时钟、相关噪声、泄漏 |

说明参数改变如何影响性能及取舍。固定 VGS 不代表固定阈值或固定导通电阻；升高的栅极对地电压也不能单独证明安全或不安全，应分析相关器件端间电压及工艺限制。

## 验证与交付

- 对关键公式进行量纲、符号、极限情况及数量级检查；用有明确单位和条件的数值例子解释设计约束。
- 复杂推导、参数扫描或可重复的图表可使用计算脚本。脚本放入项目的代码目录，和笔记中的模型、参数保持一致。
- 将解析核对、模型计算、SPICE 仿真和实测分开标注。解析脚本不是晶体管级验证；没有运行仿真时给出具体测试平台、激励、扫描变量和判据。
- 仅在本轮任务相关时建立或更新 Markdown 笔记、图表及索引；不要自动创建网页、部署、提交或发布。
- 按任务选择章节：研究范围、拓扑/时序、符号与假设、机理与推导、非理想因素、设计例子、验证状态、参考来源和开放问题。结构应服务内容，不为填满模板而生成无依据的段落。
- 交付前检查公式符号与单位一致、每个重要结论有推导或来源、相对链接有效、图表可复现、参考资料访问状态真实。指出会影响设计使用的未验证项。

## 使用方式

示例请求：

> 使用 $analog-circuit-research 研究自举开关，先明确功能级拓扑和时序，再推导 VGS 与导通电阻，分析体效应、寄生和采样误差，整理为知识笔记。没有 PDK 的结论按解析模型标注。

> 使用 $analog-circuit-research 根据这篇论文核对已有 FIA 笔记，只修订增益和噪声分析，保留其他章节。
