# Circuits & Systems Classroom 项目约定

只在当前仓库属于 Circuits & Systems Classroom 时应用。先检查实际目录和用户要求；下面是项目约定，不是其他仓库的通用要求。

## 文档位置与语言

- 根目录存放技术 Markdown 笔记，使用英文正文，与现有知识库一致；与用户沟通可以使用中文。用户指定语言时优先服从用户。
- 文件名采用主题名称加连字符，例如 `Bootstrapped-Sampling-Switch.md`；标题用清晰的英文术语，首次出现时定义缩写。
- 根目录 `README.md` 是主题目录。新增笔记时，在相应分类加入文件名和简短内容说明。
- `code/` 存放计算与绘图脚本，`figures/` 存放被文档引用的图。按主题命名，用相对链接引用；脚本从自身路径定位仓库，不依赖用户工作目录。
- `reference/` 被 Git 忽略，可以存放本地资料。公开笔记中的必要依据要给出可追溯书目信息或稳定链接，不能只依赖未跟踪的本地文件。

## 写作与证据

- 用 `$...$` 和 `$$...$$` 编写数学公式。重点公式可以使用 `\boxed{}`，但应在附近注明假设和有效范围。
- 用符号表记录含义、单位及定义；正文明确 Hz/rad/s、RMS/峰值、单端/差分以及噪声 PSD/方差。
- 开头简述分析对象和验证状态。完整拓扑未知时标注为功能级模型，列明实现所需但尚未确定的连接或时序。
- 引用论文数据时同时记录工艺、供电、频率、负载和测量条件中影响比较的参数。没有这些条件就不作定量横向排名。
- 源头元数据可以用于核实作者、标题和 DOI，不能证明已读正文。用引用编号区分外部资料和本笔记独立推导。
- 对重复出现的历史笔记格式、公式或典型参数，先核对再沿用。不要把旧笔记缺少假设或引用的做法固化为标准。

## 范围与索引

- 文档知识库与 `web/` 交互课堂分开维护。研究笔记不自动修改网页、路由或交互演示。
- 若已有 `.PROJECT.md` 或 `.FOLDER.md` 且相关文件要求同步，更新实际存在的对应文件；不为复刻旧注释而创建被忽略的空索引。
- 可在笔记顶部使用简短 HTML 注释记录输入、输出和定位。不要添加指向不存在的维护文件的指令。
- 仓库中的 skill 源码位于 `skills/analog-circuit-research/`，便于版本管理。安装副本应与源码内容一致；目录 `references/` 是 skill 指令资源，与仓库被忽略的 `reference/` 资料目录不同。
